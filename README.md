# Proyecto1-Archivos-SS26
Primer proyecto del curso de Archivos - Universidad de San Carlos de Guatemala-CUNOC - Conciste en hacer un Mini ERP (sistema de gestion comercial) que permita integrar y administrar las operaciones comerciales para una empresa dedicada a la venta y distribucion de muebles - Tecnologias utilizadas: JDK 21, Spring Boot 4, Angular 21 y PostgreSQL 18
